## Quick Setup

1. Install Python 3.10 or higher.
2. Navigate into a week's directory, create a virtual environment, and install dependencies:
   ```bash
   python -m venv .venv
   # Windows PowerShell
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```
3. Copy `.env.example` to `.env` and add your `GEMINI_API_KEY` (and `MONGO_URI` for Week 3).
4. Run the script and record your console outputs in the corresponding `2520030597_Week-X.docx` lab report template.
